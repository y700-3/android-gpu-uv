# Референсные профили MinusZero

В этой директории лежат два профиля `konabess://`. Неизвестно, для какой
прошивки они были созданы. Их содержимое декодировано и проверено, а ниже
зафиксированы точные данные файлов и структура таблиц.

Определить источник по самим профилям нельзя: встроенное поле `desc` у них
пустое. Проверка подтверждает, что оба файла читаются и не содержат внутренних
противоречий. Она не подтверждает совместимость с какой-либо конкретной
сборкой прошивки и не гарантирует стабильность на конкретном планшете.

Это именно референсные данные, а не набор профилей, собранный из исходных
файлов прошивки. Они не служат основой или вариантом по умолчанию для других
профилей в репозитории. Перед использованием обязательно сравните выбранный
файл с полной стоковой таблицей нужной прошивки.

Как устроены запросы регулятора, чем отличаются семейства профилей и как
формируются имена файлов, описано в общем
[руководстве по профилям](../../docs/profile-guide_ru.md).

Последовательность частот в файлах одинаковая, включая точки 905, 300, 200 и
100 МГц. Имена обозначают заявленные варианты -2 и -3, но после декодирования
видно лишь то, что профили различаются в девяти запросах регулятора. Чтобы
вычислить точный сдвиг относительно стока, нужна стоковая таблица прошивки, с
которой сравнивается профиль.

Для файла -3 валидатор LTBox показывает пять неблокирующих предупреждений:
четыре относятся к строкам с запросом `16`, ещё одно — к строке 100 МГц. Для
файла -2 предупреждений четыре: три для строк с запросом `16` и одно для строки
100 МГц.

## Совместимость

Привязка к прошивке неизвестна, поэтому репозиторий не заявляет ни о
совместимости этих файлов с какой-либо прошивкой, ни об их стабильности на
устройствах. Проверка охватывает только целостность контейнеров, структуру после
декодирования, хеши и размеры файлов, а также разницу между двумя профилями.
Имена файлов — лишь метки: без соответствующей стоковой таблицы они не
доказывают равномерный сдвиг на -2 или -3.
