# Андервольт GPU для Lenovo Y700 Gen 3 (TB321FU)

<p align="center"><a href="README.md">English</a> | <a href="README_ru.md">Русский</a></p>

Готовые профили андервольта GPU для Lenovo Legion Y700 Gen 3 (`TB321FU`). Их
можно импортировать через раздел «Тюнинг GPU» в LTBox или через KonaBess.

Для поддерживаемых ROW-прошивок доступны стоковые таблицы и два подхода к
андервольту:

- **Exact AOP** использует ступени питания из самой прошивки: один шаг в имени
  соответствует переходу на одну позицию вниз в списке уровней этой прошивки,
  пока не достигнут нижний предел;
- **Generic** использует классическую шкалу уровней LTBox — тот же общий подход,
  что и в старых профилях MinusZero.

Если вам нужно просто выбрать профиль и установить его, начните с
**[руководства по профилям](docs/profile-guide_ru.md)**. Там написано, откуда
скачать файлы, что сохранить для отката, чем отличаются профили и как их
проверять.
