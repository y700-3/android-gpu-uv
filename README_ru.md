# Андервольт GPU для Lenovo Y700 Gen 3 (TB321FU)

<p align="center"><a href="README.md">English</a> | <a href="README_ru.md">Русский</a></p>

Воспроизводимые профили таблицы питания GPU для Lenovo Legion Y700 Gen 3
(`TB321FU`), совместимые с LTBox/KonaBess. Для каждой поддерживаемой прошивки
здесь есть полный стоковый профиль и UV-профили, автоматически собранные из её
исходных файлов. Диффы и отчёты для релиза при необходимости генерируются
локально из тех же файлов.

> риск. Изменение таблицы питания GPU может привести к нестабильной работе,
> потере данных, невозможности загрузить систему или повреждению устройства.
> Владелец репозитория, авторы и участники проекта не несут ответственности за
> ущерб, потери и любые другие последствия использования этих файлов,
> профилей, инструкций или инструментов.

> Используйте профили только из директории с полным идентификатором вашей
> прошивки. Успешная проверка структуры не гарантирует стабильность на каждом
> экземпляре планшета. Обязательно сохраните соответствующий `stock.txt` и
> тестируйте профили осторожно.

## Типы профилей

| Тип | Значение |
|---|---|
| Stock | Полная стоковая таблица, извлечённая из соответствующей прошивки |
| Exact AOP -1/-2/-3 | Сдвиг вниз по активным значениям `gfx.lvl` этой прошивки с остановкой на минимальном уровне |
| Generic picker -2/-3 | Сдвиг по общей шкале KonaBess/LTBox для сравнения запрошенного и фактического результата |
| 903/905 МГц | Стоковые частоты или визуальный маркер применения профиля |

Универсального профиля по умолчанию нет. Разница между преобразованиями,
назначение маркера и границы экспериментов описаны в
[руководстве по профилям](docs/profile-guide_ru.md).

## Быстрый старт

1. Найдите директорию с полным идентификатором установленной прошивки.
2. Сохраните её `stock/stock.txt` для отката таблицы через LTBox. Такой профиль
   не заменяет бэкап на случай, если устройство перестанет загружаться.
3. Сверьтесь с [руководством по профилям](docs/profile-guide_ru.md) и выберите
   нужное семейство преобразования и вариант частоты.
4. Импортируйте профиль в LTBox/KonaBess, убедитесь, что выбрана нужная таблица
   GPU, и примените его.
5. Перезагрузите планшет, убедитесь, что таблица или маркер применились, и
   [проверьте стабильность](docs/validation-and-testing_ru.md#тестирование-стабильности-устройства).

Разбор сообщений LTBox и порядок оценки стабильности приведены в документе
[«Проверка и тестирование»](docs/validation-and-testing_ru.md).

## Сборка профилей из прошивки

Для сборки нужны `vendor_boot.img` и `aop.mbn` из одного пакета прошивки, а
также общий [`config.toml`](config.toml). `vbmeta.img` не используется.
Структура директорий, команды, выходные файлы, обработка ошибок и порядок
добавления новой прошивки описаны в
[руководстве по сборке](docs/building_ru.md).
