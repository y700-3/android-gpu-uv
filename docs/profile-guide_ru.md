# Как выбрать и установить профиль

Это руководство для тех, кто хочет установить уже готовый профиль. Извлекать
образы прошивки, запускать скрипты и разбираться в DTB не потребуется.
Используйте [последний стабильный релиз LTBox](https://github.com/miner7222/LTBox/releases/latest).
Настройка GPU появилась в LTBox v3.2.3. Начиная с v3.2.6 пункт бокового меню
называется **Tune GPU** в английском интерфейсе и **Тюнинг GPU** в русском. В
v3.2.3–v3.2.5 он назывался **GPU Clock/Voltage** / **Частота/напряжение GPU**. Заголовок
самой страницы — **Edit GPU Clock/Voltage** / **Изменить частоту/напряжение GPU**.
KonaBess импортирует те же `.txt`, но порядок создания бэкапа и записи зависит от версии
приложения.

## Короткий ответ

- Первый осторожный тест: `uv_1_aop_level_903mhz.txt`.
- Необязательный классический промежуточный вариант или профиль для сравнения:
  `uv_2_level_903mhz.txt`.
- Следующий шаг, если AOP -1 стабилен: `uv_2_aop_level_903mhz.txt`.
- Только для осознанного агрессивного эксперимента:
  `uv_3_aop_level_903mhz.txt`; он может быть нестабилен на части планшетов.
- Обычный откат: соответствующий `stock.txt`, если LTBox может полностью пройти
  процедуру **Тюнинг GPU** через ADB или Fastboot.

Ни один профиль не гарантирует стабильность на каждом экземпляре планшета.
Проверяйте по одному файлу. До записи сохраните `stock.txt` из релиза и отдельно
скопируйте бэкап, который LTBox создаст после проверки устройства.

## Выберите релиз для своей прошивки

Эти профили предназначены для международной **ROW-прошивки**, а не для
китайской **CN**. Должны совпадать и регион, и версия.

1. Откройте **Настройки → О планшете** и найдите версию ZUI или номер сборки.
   Название пункта может отличаться; нужен номер вида `17.5.10.272`.
2. Убедитесь, что полная строка сборки содержит `_ROW`. Если в настройках регион
   не указан, подключите планшет с разрешённой отладкой по USB и выполните:

   ```bash
   adb shell getprop ro.vendor.build.fingerprint
   ```

3. Откройте релиз с таким же номером ZUI:

| Версия ROW | Страница загрузки |
|---|---|
| `17.5.10.272` | [Релиз ZUI 17.5.10.272](https://github.com/ishad0w/tb321fu-android-gpu-uv/releases/tag/17.5.10.272) |
| `17.0.12.183` | [Релиз ZUI 17.0.12.183](https://github.com/ishad0w/tb321fu-android-gpu-uv/releases/tag/17.0.12.183) |

В этих двух релизах таблица GPU и уровни AOP совпадают. Архивы оставлены
отдельными, чтобы встроенное описание профиля указывало именно установленную
версию прошивки. Всегда скачивайте релиз, совпадающий с версией на планшете.
Если у вас CN, нужной версии нет в таблице или регион неизвестен, не выбирайте
профиль только по похожему номеру.

## Скачайте два нужных файла

На странице подходящего релиза раскройте раздел **Assets**, скачайте и
распакуйте архив, имя которого заканчивается на `_gpu_profiles.zip`.

После распаковки откройте корневую папку архива. Её имя должно заканчиваться тем
же номером ZUI, что и скачанный релиз. Например, для `17.5.10.272` откройте
`TB321FU_ROW_ZUI_17.5.10.272`. Минимальный набор выглядит так:

```text
TB321FU_ROW_ZUI_17.5.10.272/
├── stock/
│   └── stock.txt
└── uv/
    └── uv_1_aop_level_903mhz.txt
```

Для импорта нужны только два файла из этой папки:

1. `stock/stock.txt` — стоковая таблица GPU для обычного отката;
2. один файл из `uv/` — профиль андервольта для тестирования.

Для настольного LTBox храните файлы на том компьютере, где он запущен: кнопка
**Импорт** открывает системное окно выбора файла. Для Android-версии KonaBess
скопируйте их в доступную папку на планшете. В любом случае сохраните ещё одну
копию на другом устройстве или в облаке.

Не импортируйте `stock.dts`, `diff_*.md` и `release_report.md`. Это читаемые
материалы для проверки, а не профили.

## Выберите профиль

Каждый файл ниже создаётся напрямую из стока — устанавливать их по очереди не
нужно. По расчётной модели для обеих поддерживаемых прошивок самый мягкий
профиль — AOP -1, затем идёт Generic -2. AOP -2 и Generic -3 по-разному меняют
отдельные частотные точки, поэтому ни один из них не оказывается агрессивнее
на всей таблице. AOP -3 — самый агрессивный из опубликованных профилей.

| Профиль | Зачем выбирать | Компромисс |
|---|---|---|
| `stock.txt` | Вернуть исходную таблицу через **Тюнинг GPU**, пока LTBox может подключиться по ADB или Fastboot и завершить операцию | Андервольта нет; это не аварийное восстановление образов |
| `uv_1_aop_level_903mhz.txt` | Вы впервые пробуете андервольт или хотите начать с самого мягкого варианта | Самое мягкое изменение таблицы; возможная экономия энергии тоже может быть небольшой |
| `uv_2_level_903mhz.txt` | Повторить классический подход Generic в стиле MinusZero | Умеренный, но неравномерный расчётный сдвиг |
| `uv_2_aop_level_903mhz.txt` | После стабильного AOP -1 перейти к сдвигу до двух уровней из списка, извлечённого из прошивки | По расчётной модели ни в одной точке не мягче Generic -2; стабильность всё равно зависит от экземпляра планшета |
| `uv_3_level_903mhz.txt` | Проверить более сильный классический Generic-профиль | По расчётной модели на разных точках может быть как агрессивнее, так и мягче AOP -2 |
| `uv_3_aop_level_903mhz.txt` | Осознанно проверить самый агрессивный из опубликованных профилей | Экспериментальный вариант; возможны артефакты, ошибки GPU, зависания и перезагрузки |

> [!CAUTION]
> **Exact AOP -3 — экспериментальный и намеренно агрессивный профиль, а не
> вариант, рекомендуемый по умолчанию.** Даже если AOP -2 полностью стабилен,
> на AOP -3 могут появиться артефакты, ошибки GPU, зависания или перезагрузки.
> Запас стабильности различается от чипа к чипу, поэтому на одном планшете
> профиль может работать нормально, а на другом — нет. Проверяйте его только при
> наличии рабочего способа отката; одного короткого прогона бенчмарка
> недостаточно для вывода о стабильности.

Наибольшая польза обычно проявляется при длительной нагрузке на GPU: в играх,
эмуляторах и рендеринге, когда GPU часто работает на средних и высоких частотах.
Стабильный профиль может снизить потребление и нагрев GPU или отсрочить
троттлинг, но не обязан повышать FPS. В простое, при упоре в CPU или в другое
ограничение системы эффект может отсутствовать. Более агрессивный профиль не
всегда эффективнее: ошибки, сбросы GPU или снижение частоты способны свести
экономию к нулю. Сравнивайте профили при одинаковой нагрузке, целевом FPS,
температуре и режиме питания.

## Почему Exact AOP и Generic работают по-разному

**Generic** использует общую шкалу LTBox. В ней есть промежуточные уровни,
которых нет в прошивке, поэтому расчётный сдвиг может получиться слабее и
менее равномерным, чем следует из имени файла.

**Exact AOP** использует только уровни, найденные в самой прошивке. Поэтому
заранее известно, на сколько доступных ступеней сдвинется каждая строка
таблицы. Это не делает профиль автоматически безопасным: ступени не равны
фиксированному числу милливольт, а стабильность зависит от конкретного
планшета. Например, по расчётной модели на 903 МГц Generic -2 и Generic -3 дают
тот же результат, что и AOP -1, тогда как AOP -2 и AOP -3 опускаются ниже.

Сопоставление Generic рассчитано по логике из открытого кода Qualcomm Gen7.
Бинарный драйвер Lenovo из прошивки отдельно с этим кодом не сверялся.

Точный алгоритм сопоставления, его ограничения и значения каждого профиля
собраны в
[таблице по частотам](technical-reference_ru.md#таблица-профилей-по-частотам).
В техническом описании также приведены результаты для всех 47 строк, ссылки на
источники и формулы.

## Выберите 903 или 905 МГц

- **903 МГц** сохраняет все стоковые частоты. Выбирайте его, если хотите
  проверять только андервольт.
- **905 МГц** заменяет в таблице каждую точку 903 МГц на 905 МГц. Этот маркер
  помогает убедиться, что изменённая таблица действительно используется.

Разница составляет всего `+0,2215%` и не даёт заметного прироста
производительности. Вариант 905 МГц одновременно меняет не только уровень
питания, но и частоту. Если маркер не нужен, выбирайте 903 МГц.

При одинаковом семействе и числе ступеней варианты 903 и 905 МГц содержат
одинаковые запросы регулятора и одинаковые поля, не связанные с частотой. В
варианте 905 МГц меняются только три стоковые ячейки частоты, равные 903 МГц.

## Установка, проверка и откат

До записи профиля подготовьте два варианта восстановления:

- `stock.txt` из релиза — для обычного отката через **Тюнинг GPU**, если LTBox
  может подключиться к планшету по ADB или Fastboot и завершить операцию;
- всю папку `backup_konabess`, которую LTBox создаёт после успешной проверки
  устройства, — для возможного ручного восстановления сохранённой пары образов.

`backup_konabess` не нужно скачивать из этого репозитория или релиза. LTBox
создаёт папку после того, как **Тюнинг GPU** закончит считывать устройство, и
показывает путь в окне вывода или журнале. Откройте указанный путь и скопируйте
всю папку `backup_konabess` в другое место до продолжения работы.

Бэкап сохраняет пару образов в том состоянии, в котором она находилась на
планшете во время считывания. Считать её заводским стоком можно только в том
случае, если до этого не менялись сами образы, а не только таблица GPU. Храните
два файла вместе и не смешивайте образы, полученные при разных проверках.

LTBox использует одно фиксированное имя папки, поэтому каждая следующая
успешная проверка устройства заменяет её содержимое. Эти файлы предназначены
для ручного аварийного восстановления через EDL, а не для автоматического
отката. Само аварийное восстановление выходит за рамки этого руководства.

Если LTBox ещё не видит планшет или у вас нет подходящего для TB321FU
**Загрузчика EDL** (`EDL Loader` в английском интерфейсе), сначала прочитайте
официальные инструкции по [подключению устройства](https://miner7222.github.io/ltbox/en/connecting-a-device.html)
и [выбору загрузчика EDL](https://miner7222.github.io/ltbox/en/root-a-device.html#edl-loader).

Чтобы записать профиль через LTBox:

1. Подключите планшет по USB: либо с разрешённой отладкой, либо в режиме
   Bootloader/Fastboot. Откройте **Тюнинг GPU**, выберите правильный
   **Загрузчик EDL** и нажмите **Далее**.
2. Когда LTBox закончит проверку устройства и создаст или обновит
   `backup_konabess`, скопируйте папку в другое место. Если таблицу уже меняли,
   не помечайте эту копию как стоковую.
3. В окне **Выбор целевого DTB** проверьте выбранную строку. Для указанных выше
   релизов нужен DTB #4: `qcom,pineapple`, `Adreno750v2`, 4 группы и 47 уровней.
   Выбирайте его, только если LTBox показывает те же данные. При несовпадении
   остановитесь.
4. В окне **Таблица GPU устройства** нажмите **Импорт**, выберите нужный
   `uv_*.txt` и проверьте описание и значения профиля.
5. Нажмите **Далее**. В окне **Подтверждение операции KonaBess** проверьте
   сводку и нажмите **Старт**.
6. Перезагрузите планшет и повторно прочитайте таблицу в LTBox. Сверьте
   изменённые строки с соответствующим файлом `diff_*.md` из релиза, где
   изменения приведены в читаемом виде.
   Для варианта 905 МГц дополнительно проверьте маркер 903 → 905 МГц. Делайте
   это только после сохранения предыдущего бэкапа: повторная успешная проверка
   заменит папку `backup_konabess` копией уже изменённых образов.
7. Пройдите [проверку стабильности](validation-and-testing_ru.md#тестирование-стабильности-устройства),
   прежде чем переходить на более агрессивный профиль.

Если профиль оказался нестабилен, но планшет доступен по ADB или Fastboot и
LTBox может полностью выполнить **Тюнинг GPU**, импортируйте соответствующий
`stock.txt`, запишите его тем же способом и перезагрузитесь. `stock.txt`
восстанавливает только таблицу GPU и не предназначен для восстановления пары
исходных образов. Файл не поможет, если LTBox не может подключиться к устройству
или завершить операцию.

## Частые вопросы

### Что означает имя файла?

В имени `uv_2_aop_level_903mhz.txt`: `uv` означает андервольт, `2` — сдвиг вниз
не более чем на две ступени, `aop` — использование списка уровней из прошивки,
а `903mhz` — сохранение стоковой частоты 903 МГц. Если в имени нет `aop`, это
Generic-профиль. Число означает количество ступеней вниз: в Generic-профиле —
по общей шкале LTBox, в Exact AOP — по списку уровней конкретной прошивки. Это
не милливольты и не проценты.

### Нужны ли образы прошивки и скрипт сборки?

Нет. `vendor_boot.img`, `aop.mbn` и `build_profiles.py` нужны только
мейнтейнерам, которые создают новый набор. Для установки готового релиза
достаточно `stock.txt` и одного файла `uv_*.txt`.

### Сообщение `Found N advisory finding(s)` в LTBox — это ошибка?

Само по себе — нет. Независимое декодирование опубликованных профилей и проверка
по текущим правилам валидатора LTBox дают такие ожидаемые результаты:

| Профиль | Ожидаемые предупреждения |
|---|---|
| Generic -2, 903 или 905 МГц | 8: четыре запроса `48` и четыре запроса `16` |
| Generic -3, 903 или 905 МГц | 12: четыре запроса `48` и восемь запросов `16` |
| Exact AOP -1/-2/-3, 903 или 905 МГц | 0 |

Предупреждения Generic — это неблокирующие сообщения о закодированных запросах
за пределами диапазона стоковых значений, наблюдаемого LTBox. Ожидаемое
количество не доказывает стабильность. Если оно отличается, изучите каждое
предупреждение и все блокирующие ошибки, затем до записи ещё раз проверьте
точный файл профиля, релиз прошивки и выбранную таблицу GPU.
